# ssh

Exercises on SSH: private keys, key pair creation and client configuration.

| File | Description |
| ---- | ----------- |
| 0-use_a_private_key | Connects to the server with ~/.ssh/school as ubuntu |
| 1-create_ssh_key_pair | Creates a 4096-bit RSA key pair named school (passphrase: betty) |
| 2-ssh_config | SSH client config: use ~/.ssh/school, refuse password auth |
